# Hermissa: Portfolio & Style

Kannst du mir bitte ein Website Design visualisieren, die zu der Make Up Artistin im Anhang passt? Ihre Zielkundschaft ist eher in Richtung Fashion Shown oder ähnliches. Sie ist immer noch am Start aber hat bereits ein gutes Portfolio. Die Webseite sollte minimalistisch aufgebaut sein, Fokus auf das Portfolio und "ÜBER MICH" und natürlich ein kontaktformular. Es kann auf eine Angebot/Produkt/Preis Section verzichtet werden. Wie würdest du es professionell gestalten, sodass es zum branding passt? Ihr Markenname ist "HERMISSA" das logo ist im anhang. das verschmolzene HM ist das hauptlogo und wo immer platz ist ist das Wort HERMISSA neben das HM hinzuzufügen (z.b in der menubar). das HM möchte ich auch als kleines symbol neben dem webseitname in der menübar in google chrom. los
